## Projects

### [StratEcho](https://github.com/IvanVenkov712/StratEcho)
A Python backtesting engine built from scratch, supporting trading strategies, order execution, portfolio accounting, transaction costs, and performance analysis.

### [Hypothiq](https://github.com/IvanVenkov712/Hypothiq)
A web application for running and analyzing trading strategy backtests. Built with FastAPI, Backtrader, and React. Currently under development.

### [HTTP Server](https://github.com/IvanVenkov712/Http-Server)
A lightweight HTTP/HTTPS server for Windows, written in C++, with asynchronous request processing and configurable server behavior.

### [FMI Scheduler](https://github.com/IvanVenkov712/FMI-Scheduler)
A university scheduling and room management system built with PHP and MySQL.

### [Boomvox](https://github.com/IvanVenkov712/Boomvox)
A music platform project with a Spring Boot backend, PostgreSQL, Amazon S3 storage, and asynchronous audio processing.
